# **Minecraft Anchor Macro**

A lightweight, automated Python script designed to streamline Respawn Anchor sequences (Anchor -> Glowstone -> Totem) in Minecraft. Built with humanized, randomized delays to ensure reliable execution and smooth packet synchronization.

---

## ¨**Features**

* **Complete Automation Sequence:** Automatically cycles through your Anchor, Glowstone, and Totem binds with precise right-click triggers.
* **Humanized Anti-Cheat Bypass:** Utilizes randomized delays (ranging from 15ms to 50ms) to mimic natural human variation and avoid rigid macro flags.
* **Hold-to-Repeat Logic:** Continuously loops while your activation key is held down, ensuring every cycle finishes cleanly before stopping or restarting.
* **Session Counter:** Tracks how many times the macro has been successfully triggered during your session.
* **Clean Terminal Interface:** Features a custom ANSI-colored ASCII banner.

---

## **Prerequisites**

Make sure you have **Python 3.x** installed on your system. You will also need the following external Python libraries:
* `keyboard` (pip install keyboard)
* `mouse`    (pip install mouse)
